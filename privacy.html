Privacy

hisia.live and the “hisia stream” application · last updated 18 September 2026

hisia.live is a personal project run by one person. It collects nothing about you, has no accounts, and has no users other than its operator.

The website

The page is static and hosted on GitHub Pages. It sets no cookies, runs no analytics and loads nothing from advertising or tracking services. It fetches only its own files from this domain.

It does keep a few things in your own browser's storage, and none of them are ever transmitted: a display preference, the state of the player between page loads, and a small local diagnostic record — when a listening session started and ended, how long it lasted, how many tracks played, whether audio was still playing, and your browser's user-agent string. That record exists so the operator can debug playback on his own device; it is only ever displayed on the device that made it, by opening the page with ?diag=1. Clearing your browser data removes all of it. As with any website, the host (GitHub) processes ordinary request information such as IP addresses in order to serve the page.

The “hisia stream” application

“hisia stream” is private tooling that broadcasts this radio to its own YouTube channel and to Twitch. It is not offered to anyone else and has no sign-in.

Both platforms receive one thing: the broadcast itself — the same audio and the same page you can see here, encoded and sent as video. Nothing about you is included in it. If you watch on YouTube or Twitch rather than here, that platform's own privacy policy governs what it collects from you, and this project neither receives nor asks for any of it. The Twitch side uses a stream key only, with no access to any account data.

It uses the YouTube Data API, with the youtube.force-ssl permission, for one purpose: to create, bind, start and end the operator's own live broadcasts on the operator's own channel. It does not read viewers' data, comments, subscriptions or analytics, and it touches no channel but its own.

The only credential it holds is an OAuth refresh token for that channel, stored on the operator's own server and used solely for the calls described above. It is not shared with anyone, is never sent anywhere except to Google, and can be revoked by the operator at any time at myaccount.google.com/permissions, which ends the application's access immediately.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Sharing

Nothing is sold, shared or passed to third parties. The only services involved are GitHub, which hosts the page, and Google/YouTube and Twitch, which carry the broadcast.

Contact

Questions about any of this can be sent through the stream chat.
