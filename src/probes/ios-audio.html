iOS audio probe

Run one test at a time. Where a test says to lock the screen, lock it, count to twenty, unlock, then read the log. Judge sound by ear — the log cannot hear.

A · does el.volume work?

Plays a plain <audio>, ramps the volume down to 0.15 over 3s and back up over 3s. Listen.

B · does the graph survive a screen lock?

Plays through createMediaElementSource → gain → destination. Start it, lock the screen, count to twenty, unlock.

C · can it hand off to a plain element on the way into the lock?

Same graph, but on hidden it starts a second bare element at the same position and pauses the graph one; on visible it hands back. Start it, lock, count to twenty, unlock. Listen for a gap at each handover.

D · does resume() bring a dead graph back?

Run B first and let it die. Then unlock and press this — no reload.
