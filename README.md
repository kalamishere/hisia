# hisia · World Sound

Continuous radio of AI-generated variations on this week's charts around the world, following the sun into evening. An experiment from [Decimal Points](https://decimalpoints.substack.com/).

- `index.html` — the page (static, no build)
- `library.json` — this week's cities, readouts, prompts and tracks
- `audio/` — the tracks (SA3 medium on Hugging Face, two-stage seeding, no real recordings as input)

Every track is AI-generated. Artist and track names are fictional. Powered by Stability AI.
